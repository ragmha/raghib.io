## The Vision

I wanted a personal site that felt different. Not another generic portfolio with a hero section and a grid of cards. I wanted something that reflected how I actually work — in the terminal.

The result is [raghib.io](https://raghib.io) — a site where the homepage is an interactive terminal, the blog looks like filesystem output, and every page feels like you're `ssh`-ing into my brain.

## Tech Stack

Here's what powers this site:

- **Next.js 16** with the App Router and React Server Components
- **Tailwind CSS 4** with a custom Catppuccin Mocha color theme
- **MDX** for writing blog posts with embedded React components
- **Shiki** for syntax highlighting that matches the terminal aesthetic
- **GitHub API** for auto-populating the projects page

## The Terminal Component

The heart of the homepage is the interactive terminal. It supports slash commands, autocomplete, and a typewriter greeting animation:

```typescript
const LINK_COMMANDS: Record<string, string> = {
  '/linkedin': 'https://www.linkedin.com/in/ragmha/',
  '/projects': '/projects',
  '/writing': '/writing',
}
```

Every command is either a navigation link or a text output. The autocomplete shows when you type `/` and supports keyboard navigation.
